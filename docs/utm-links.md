# 社群連結怎麼加 UTM

給貼文、個人檔案與 LINE 官方帳號用的網址。改的人不必會寫程式。統計後台要等 `docs/analytics.md` 的 GoatCounter 網站代碼填上之後才看得到數字。

## 三個欄位

網址後面這三段請保持英文，不要空格，不要加姓名或電話。

| 欄位 | 填什麼 | 這次怎麼填 |
| --- | --- | --- |
| `utm_source` | 哪個平台 | 見下一表。一個平台一個字 |
| `utm_medium` | 連結放在哪一種位置 | 不確定就用 `social`。個人檔案或自我介紹用 `profile`。單篇貼文用 `post` |
| `utm_campaign` | 這一檔活動的名字 | `repositioning-2026-12` |

平台對照：

| 平台 | `utm_source` |
| --- | --- |
| Facebook | `facebook` |
| Instagram | `instagram` |
| Threads | `threads` |
| TikTok | `tiktok` |
| YouTube | `youtube` |
| LINE 官方帳號 | `line` |

YouTube 目前沒有放在網站頁尾，仍然可以拿這裡的連結去貼影片說明。

下一檔活動只改最後一段，用英文短名加年月，例如 `new-year-2027-01`。不要用中文。

GoatCounter 後台的 Campaigns 看得到活動名稱（`utm_campaign`）和來源（`utm_source`）。`utm_medium` 會留在網址上，但這個後台不會單獨列出 medium。若要在報表裡直接分開個人檔案和貼文，把活動名稱加上後綴，例如 `repositioning-2026-12-profile` 或 `repositioning-2026-12-post`，其他兩段不要改。

語言頁本身已經帶國家：繁中 `country=TW`、越南文 `country=VN`、英文 `country=all`、印尼文 `country=ID`、泰文 `country=TH`、菲律賓文 `country=PH`。請整段複製，不要删掉 `country`。

## 個人檔案與單篇貼文

只要把 `utm_medium=social` 改成 `profile` 或 `post`。下面是繁中、Facebook 的兩個例子：

- 個人檔案：https://crossing-proxy-taiwan.github.io/zh/?country=TW&utm_source=facebook&utm_medium=profile&utm_campaign=repositioning-2026-12
- 單篇貼文：https://crossing-proxy-taiwan.github.io/zh/?country=TW&utm_source=facebook&utm_medium=post&utm_campaign=repositioning-2026-12

其他語言與平台用同一種改法。
