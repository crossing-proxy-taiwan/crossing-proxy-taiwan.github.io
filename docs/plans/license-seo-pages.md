# 計畫：駕照文件服務的多語 SEO 頁

這是計畫，不是已開放的新服務頁。沒有放進導覽、sitemap 或首頁連結。`robots.txt` 不允許抓取 `/docs/plans/`。

這次沒有另外做公開 HTML 草稿。GitHub Pages 會把儲存庫裡的 HTML 直接提供出去，即使沒有連結，知道網址的人仍開得到。為避免被當成已上線的服務頁，草稿只留在這份文件。

## 可以做的頁

六個語言各一頁，沿用現有網址層級，例如：

- `/zh/driving-license/`
- `/en/driving-license/`
- `/vi/driving-license/`
- `/id/driving-license/`
- `/th/driving-license/`
- `/fil/driving-license/`

每頁有自己的 title、description、canonical 與六語 hreflang。結構化資料只在經營者確認該頁可以公開之後，才放已開放的 Service。

## 頁面上可以寫的

與現有「駕照文件代辦」相同的範圍：考照預約、重考報名、外國駕照換發流程、文件整理、筆試與交通規則說明、監理站流程諮詢，以及翻譯或陪同的詢問。資格與文件依台灣監理機關規定。不保證考試通過或換照成功。收費仍是 LINE 個別報價，不寫金額。

## 頁面上不可以寫的

通過率、客戶人數、政府授權、代辦費用、可服務縣市清單、電話，以及尚未確認可以承接的細項。翻譯與陪同維持「先詢問、依個案確認」。

## 上線前

母語校對完成，而且 JAS 明確同意這些獨立頁可以公開。在那之前，首頁卡片仍是唯一的公開入口。
