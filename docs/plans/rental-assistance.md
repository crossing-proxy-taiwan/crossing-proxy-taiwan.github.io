# 計畫：外籍房客租屋協助

這是計畫。沒有新增公開服務，也沒有把任何租賃項目改成已開放。

現有的「機車短中期租賃」與「生活用品與家具租賃」維持規劃中。這份計畫說的是另一件事：協助外籍房客理解租屋流程。兩者不要混成同一個已開放項目。

## 經營者確認前不能公開成已開放

- 實際範圍：只說明租約與陪同看屋，還是也媒合房源。
- 是否需要租賃相關資格或合法合作對象。未確認前不寫成可直接辦理，也不寫成合作轉介。
- 可服務縣市。
- 是否收費，以及如何在 LINE 報價。本站仍不公告價格。
- 不代收租金、不經手匯款，除非日後另有確認。目前維持不經手匯款。

## 若以後做成服務

用新的服務 id，狀態先放 `planned`。六語一起補。表單只組成 LINE 草稿，不收集護照、居留證或身分證號碼。JAS 書面確認範圍與資格之後，才可以改成 `open`。
